# Quantum Disease Variant Detector

A project that explores quantum and classical machine learning
for genetic variant classification.

## Objectives
- Analyze genetic variant data.
- Build classical machine learning models.
- Explore quantum machine learning models.
- Compare model performance.

## Technologies
- Python
- Pandas
- Scikit-learn
- Qiskit
- FastAPI

## Project Status
Under Development

## Disclaimer
This project is for educational and research purposes only.
It is not intended for medical diagnosis.
